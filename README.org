* Installation
Version 3.0 requires ~typed-amb~ 3.0.

Install the package with ~raco pkg install --auto ambKanren~.

* Documentation
See the [[https://docs.racket-lang.org/ambKanren/index.html][online documentation]], or run
~raco docs ambKanren~ after installing the package.

* Usage
Each language has its own module: ~typed/microKanren/amb~ for
microKanren (Hemann and Friedman, 2013), and
~typed/miniKanren/amb/trs1~ and ~typed/miniKanren/amb/trs2~ for the
languages of the first (2005) and second (2018) editions of /The
Reasoned Schemer/.

#+begin_src racket
#lang typed/racket/base
(require typed/microKanren/amb)
(run* (q) (conde [(== q 'red)] [(== q 'green)]))
#+end_src

#+begin_src racket
#lang typed/racket/base
(require typed/miniKanren/amb/trs1)
(run* (q) (conde [(== q 'red)] [(== q 'green)]))
#+end_src

#+begin_src racket
#lang typed/racket/base
(require typed/miniKanren/amb/trs2)
(defrel (coloro c) (conde [(== c 'red)] [(== c 'green)]))
(run* q (coloro q))
#+end_src

* Search scheduling in v3
The search strategy is the merger of amb, ~current-amb-merger~; the
v2 parameters ~current-amb-depth-first?~ and ~current-amb-fair?~, and
~#:empty-handler~, are gone.  In microKanren, ~Zzz~ and the forms
that use it pause before running a goal.  In TRS2, ~defrel~ pauses at
each call to the relation.  If an infinite branch can keep another
branch from giving an answer, select a fair merger explicitly.

#+begin_src racket
(require typed/amb typed/amb/merge)
(parameterize ([current-amb-merger amb-interleave])
  (run 1 q (coloro q)))
#+end_src

~run~ reads ~amb-generate*~ directly.  Committed choice passes on the
pauses while it looks for the first answer, instead of hiding them in a
sequence of answers.  With ~amb-interleave~ and the default shuffler,
TRS2 matches the answers and order of the book examples covered by
the tests.  TRS1 uses ~amb-append~ for its depth-first forms and
~amb-alternate~ for its interleaving forms.  Failure is ~amb-fail~.
The differences in answer order under other mergers, the measured
times, and the scripts that produced them are kept on the
[[https://github.com/NoahStoryM/ambKanren/tree/archive/v3-research][archive/v3-research]]
branch.
