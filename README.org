* Installation
Version 3.0 requires ~typed-amb~ 3.0.

Install the package with ~raco pkg install --auto ambKanren~.

* Documentation
See the [[https://docs.racket-lang.org/ambKanren/index.html][online documentation]], or run
~raco docs ambKanren~ after installing the package.

* Usage
Each language has its own module: ~typed/microKanren/amb~ for
microKanren (Hemann and Friedman, 2013), and
~typed/miniKanren/amb/trs1~ and ~typed/miniKanren/amb/trs2~ for the
languages of the first (2005) and second (2018) editions of /The
Reasoned Schemer/.

#+begin_src racket
#lang typed/racket/base
(require typed/microKanren/amb)
(run* (q) (conde [(== q 'red)] [(== q 'green)]))
#+end_src

#+begin_src racket
#lang typed/racket/base
(require typed/miniKanren/amb/trs1)
(run* (q) (conde [(== q 'red)] [(== q 'green)]))
#+end_src

#+begin_src racket
#lang typed/racket/base
(require typed/miniKanren/amb/trs2)
(defrel (coloro c) (conde [(== c 'red)] [(== c 'green)]))
(run* q (coloro q))
#+end_src

* Search scheduling in v3
The old ~current-amb-depth-first?~, ~current-amb-fair?~ and
~#:empty-handler~ interfaces are replaced by ~current-amb-merger~
and explicit ~amb-pause~ events. For recursive TRS2 and microKanren
searches, select a fair merger explicitly:

#+begin_src racket
(require typed/amb typed/amb/merge)
(parameterize ([current-amb-merger amb-interleave])
  (run 1 q (coloro q)))
#+end_src

~run~ consumes ~amb-generate*~ directly. Committed choice forwards
pauses while looking for the first answer; it does not hide them in
an answers-only sequence. TRS1 uses append for depth-first forms and
alternate for answer-interleaving forms, with local binding for conjunction.
Answer ordering differences and measured v2/v3 test times are recorded
in ~MIGRATION-V3.md~.
